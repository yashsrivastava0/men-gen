### CLAUDE

**Short version:** it's a Python 3.12 backend on FastAPI and Postgres, using SQLAlchemy 2.0 as the ORM. There's no frontend framework yet, and LLM calls go through one custom gateway.

## Language and tooling
- **Python 3.12–3.13**, a **uv** workspace monorepo (`packages/*`, `apps/*`, `agents/*`), with `just` as the command runner.
- **Lint and format:** ruff.
- **Types:** pyright.
- **Layering:** import-linter enforces that engines never import each other.
- **Tests:** pytest, pytest-asyncio, hypothesis (property tests) and pytest-cov.

## Backend
- **FastAPI + uvicorn** for the APIs: `context-api` on port 8100, `llm-gateway-api` on 8101, and the Compass and Research agent servers.
- **Pydantic v2 and pydantic-settings** for all models, schemas and config. `mde_contracts` is the frozen set of shared models.
- **structlog** for logging.
- **httpx** for HTTP calls.
- **PyYAML and Jinja2** for data-driven content. Catalogs, question banks, size bands and prompts are YAML or `.jinja` files, not hardcoded.

## Database and ORM
- **Yes, an ORM: SQLAlchemy 2.x in async mode** (`sqlalchemy[asyncio]`).
- **Alembic** handles migrations, append-only.
- **PostgreSQL via psycopg 3** (`psycopg[binary,pool]`, with a connection pool).
  - It runs as a private cluster on **port 54329** (`just db-up`).
  - Port 5432 is never used.
- **No SQLite**, even in tests. Tests create an ephemeral Postgres database.
- **Layout:** `mde_persistence` holds the models, repositories, store and job worker. The worker is a `SKIP LOCKED` job queue.
- **Storage style:** documents such as the Compass Brief are stored as JSONB versions, so adding Brief sections needed no migration.
- **Identifiers and types:** IDs are prefixed ULIDs (`ses_`, `evt_`, `call_`). Money is `Decimal` or integer micro-dollars. Timestamps are timezone-aware UTC.

## LLM layer
- **`mde_llm_gateway`** is the only package allowed to import the `openai` SDK.
  - It handles providers, retries, strict schema validation, a budget guard, a spend ledger and cassettes.
  - There are **no agent frameworks** (no LangChain and the like).
- **Call model:** every call has a versioned call spec, a mock handler and a deterministic fallback. Flow is plain code, with single structured calls and no agent loops.
- **Model:** `gpt-6-luna`.
- **Live calls:** they need `LLM_MODE=live` and `[live-mode rule phrase]=1`, and spend is capped.

## Agents
- **Compass** (`agents/compass`) is the discovery engine. It adds file parsing for uploads:
  - `pypdf`
  - `python-docx`
  - `openpyxl`
  - `python-pptx`
- **Research** (`agents/research`, in progress on this branch) adds:
  - `trafilatura` for page extraction
  - `jsonschema`
  - `tld` and `regex` for URL and text handling
  - a Tavily search adapter, with fetch and robots handling
- **Others:** `discovery`, `spec-builder`, `spec-loader` and `flow` (the state machine and gates) are the older Context Engine packages.

## Frontend
- **`apps/web/console` is plain static HTML, CSS and vanilla JS** with no framework or build step.
  - It's tested with Python source-level tests and a Node syntax check.
  - The README mentions React "later".
- **The product's output** is an `APP_SPEC.md` for a separate engine that generates an Expo/React Native app. That engine isn't built here.

## Not used
- No Docker (Docker Desktop is deliberately left alone).
- No SQLite.
- No Redis or Celery. The queue is Postgres.
- No agent frameworks.

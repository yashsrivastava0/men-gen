## 3. Design (as built)

- Needs Registry: `agents/compass/src/mde_compass/catalog/slots.yaml` has 44 needs, each with `answer_spec {sufficient, aspects, fact_types, min_facts}`, `universal`, `domain_topics`. Frames (17) are style guides/examples. Need status `satisfied|partial|missing|assumed` is computed by code from facts' `aspects` (`need:aspect`, `need:*` = complete).
- Interview Memory (Postgres, Compass's own Alembic history `compass_alembic_version`, head `0002`): tables `compass_qa` (versioned), `compass_facts` (FCT-###, verbatim quote, `unverified_quote`, supersession, `effects`, `aspects`; trigger `trg_compass_fact_guard` refuses DELETE and changes of statement/quote/created_at), `compass_interview_summary`, `compass_batches` (unique session+mode+inputs_hash). In-memory twin; shared contract suite (`store/contract.py`).
- Slots are a view over facts: `SlotStore` stays the only write path; `fact_projector` writes slots with provenance ref `FCT-###`; an unverified quote projects as `model_knowledge` so it can reach Default tier but never Locked.
- Pipeline (`engine/question_pipeline.py`): `cmp.plan_questions` -> code validators (`engine/question_validators.py`, 28 issue codes) -> `cmp.audit_questions` -> one repair (now only if too few survive) -> drop -> flagged fallback only if nothing survives. A fallback is a failure: card `fallback: true`/`origin: "fallback"`, call log `outcome: fallback`, `BatchRecord.used_fallback`, `meta.interview.fallback_count`; must be 0 live.
- Round 0 is two chained turns inside `handle_event`: playback commit, then an internal `prepare_questions` Command with an `int_...` event id (ADR 0004: no transaction across a model call; idempotent).
- Follow-up policy: depth <= 2, follow-ups <= 40% of base questions, one per need; a second vague answer is assumed visibly. Budgets: Quick 5, Standard 12, Thorough 25 (follow-ups included). Stop rules: coverage, budget, fatigue, "that's enough"/finish with defaults. "I do not understand" rewrites once (`cmp.rephrase_question`), then the engine decides; "I do not know" simplifies once then records you-decide.
- Brief: new optional list section `domain_facts` (read-only), `meta.interview` block (popped from the hash), `DiscoveryPlan.interview_budget`; hash stable (empty `domain_facts` omitted; stored pre-change fixture test). `compile_ledger` fills EMPTY slots only; every active fact ends up cited, placed in `domain_facts`, or `not_used` with a reason; leftovers are placed and counted in `meta.interview.facts_unreferenced`.
- Consumer views carry facts tagged for that consumer, values only, no quote.
- Spend: `ledger_spend.compass_spent_micros()` adds committed cost of every `cmp.*` reservation in the gateway ledger (read-only); live `build_service` reconciles `CompassBudget` with it.

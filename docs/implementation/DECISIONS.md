# Decision log

Newest entries go at the bottom of each section. Format: date, decision, alternatives, reason. Non-trivial decisions only (hard rule 12). Contract changes after the v1 freeze are logged here too (additive: no version bump; breaking: ADR + bump). Environment decisions are summarized in [ADR 0002](../adr/0002-environment-adaptations.md).

## Decisions

### D-001: Repo root is `Mobigen` with its own `git init` (2026-11-08)
- **Decision:** run `git init -b main` inside `Mobigen`.
- **Alternatives:** commit into the home directory repo.
- **Reason:** `C:\Users\<user>` is itself a git repo with no commits and a huge untracked tree; committing there would be wrong. `.gitignore` is written before the first `git add` so `.env` can never be staged.

### D-002: Python 3.13.7 via uv, hatchling backend (2026-11-08)
- **Decision:** `.python-version` 3.13, `requires-python >=3.12,<3.14`, hatchling as build backend.
- **Alternatives:** 3.14 (installed but newer than the brief's target and some dependencies lag); `uv_build` backend.
- **Reason:** matches the brief (3.13, 3.12 acceptable) and is already installed; hatchling is the boring, well-supported choice.

### D-003: Private PostgreSQL 18 cluster on port 54329 (2026-11-08)
- **Decision:** `scripts/dev_db.py` runs `initdb` from `C:\Program Files\PostgreSQL\18\bin` into `data/pg` and starts it on 127.0.0.1:54329 (trust auth). `docker-compose.yml` stays for CI and other machines. Tests create an ephemeral database per session on this server.
- **Alternatives:** unpause Docker Desktop and use compose; use the user's Postgres on 5432; `pgserver` embedded Postgres; SQLite (forbidden).
- **Reason:** Docker Desktop is manually paused by the user and other projects' containers live there, so it is not touched; 5432 and another PG belong to other projects. This is rung 2 of the brief's availability ladder (local binary on a free port).

### D-004: Portable file lock (2026-11-08)
- **Decision:** `mde_core.filelock` uses `msvcrt.locking` on Windows and `fcntl.flock` elsewhere, for the budget ledger.
- **Alternatives:** require POSIX; third-party `portalocker`.
- **Reason:** the brief names `fcntl.flock`, which does not exist on Windows; a tiny in-repo helper avoids a dependency and is testable with parallel processes.

### D-005: `.env` has `OPENAI_API_KEY` twice (2026-11-08)
- **Decision:** leave the file untouched; settings and doctor tolerate duplicates (last value wins); never print the key.
- **Alternatives:** dedupe the file.
- **Reason:** harmless, and editing a secrets file is outside the job's remit.

### D-006: `just` via `uv tool install rust-just`; PowerShell windows-shell (2026-11-08)
- **Decision:** install `just` with uv; justfile sets PowerShell as the Windows shell; recipes are plain `uv run ...` commands.
- **Alternatives:** `choco install just`; require Git Bash.
- **Reason:** no admin install needed; recipes stay shell-agnostic.

### D-007: `CallSpec` and gateway types live in `mde_contracts` (2026-11-08)
- **Decision:** `CallSpec`, `CallContext`, `CallResult`, `Usage`, `GatewayClient` are in contracts; `mde_prompts` defines spec instances; the gateway receives a registry at construction.
- **Alternatives:** define `CallSpec` in `mde_prompts` as the brief 7.2 wording suggests.
- **Reason:** layering says the gateway depends only on contracts/core, so it cannot import `mde_prompts`.

### D-008: Strict-schema-safe slot values in LLM output models (2026-11-08)
- **Decision:** slot values are `value_text | value_list | value_bool` (nullable), never free-form JSON or `dict`.
- **Alternatives:** `Any`/JSON string values.
- **Reason:** OpenAI strict schemas forbid open objects; typed fields stay valid and locally re-validatable.

### D-009: Contract freeze policy (2026-11-08)
- **Decision:** v1 is tagged `contracts-v1`. Additive changes (optional fields, new models, new protocol methods with defaults) are made by the lead only and logged here without a version bump. Breaking changes need an ADR, a version bump and all consumers updated together.
- **Alternatives:** version-bump every change (too slow for parallel agents); no freeze.
- **Reason:** parallel engineers will inevitably need additions; strictness is reserved for what could break consumers.

### D-010: Repository protocols in contracts (2026-11-08)
- **Decision:** `Store` / `UnitOfWork` and repository protocols live in `mde_contracts.ports`; `flow` is built and unit-tested against in-memory fakes, `persistence` implements them on Postgres.
- **Alternatives:** `flow` imports `persistence` directly (allowed by layering, but serializes the work).
- **Reason:** lets flow and persistence be built in parallel; in-memory fakes are not SQLite and are allowed in unit tests.

### D-011: Parallelism ceiling (2026-11-08)
- **Decision:** at most 4 to 5 subagents at once; agents run pyright only on their own package paths and start no background processes.
- **Alternatives:** the brief's "about five" without limits.
- **Reason:** about 3.7 GB free RAM, and low memory kills background shells.

### D-012: Archetype ids are plain strings (2026-11-08)
- **Decision:** `ArchetypeId` is `str`, validated against content at runtime.
- **Alternatives:** a `Literal` of the five MVP archetypes.
- **Reason:** hard rule 8 (nothing hardcoded to one app type); new archetypes become data.

### D-013: `MDE_FORBID_LIVE` (2026-11-08)
- **Decision:** the pytest autouse fixture sets `MDE_FORBID_LIVE=1`; constructing a live provider then raises `LiveCallForbidden`.
- **Alternatives:** rely only on `LLM_MODE`.
- **Reason:** a test-only key makes "fail any live attempt outside `live` tests" provable.

### D-014: Hook commands anchored to `$CLAUDE_PROJECT_DIR` (2026-11-08)
- **Decision:** `.claude/settings.json` hooks run `python "$CLAUDE_PROJECT_DIR/.claude/hooks/<script>.py"`.
- **Alternatives:** relative `python .claude/hooks/...`.
- **Reason:** a relative path broke as soon as the session working directory was a subfolder (seen in testing).

## 3. Design as built
- **Needs Registry:** `catalog/slots.yaml`, 44 needs each with `answer_spec {sufficient, aspects, fact_types, min_facts}`, `universal`, `domain_topics`. 17 frames kept as style guides/examples. Need status `satisfied|partial|missing|assumed` is computed by code from facts' `aspects`.
- **Interview Memory (Postgres, own Alembic history, head 0002):** `compass_qa` (versioned), `compass_facts` (FCT-###, verbatim quote, `unverified_quote`, supersession, effects, aspects; a trigger refuses DELETE and edits of statement/quote/created_at), `compass_interview_summary`, `compass_batches`. In-memory twin with a shared contract suite.
- **Slots are a view over facts:** the fact projector writes slots with provenance `FCT-###`; an unverified quote projects as `model_knowledge` so it can reach Default tier but never Locked.
- **Question pipeline:** `cmp.plan_questions` -> code validators (28 issue codes) -> `cmp.audit_questions` -> one repair (only if too few survive) -> drop -> flagged fallback only if nothing survives. A fallback is a failure (card `fallback: true`, call log `outcome: fallback`, `meta.interview.fallback_count`); target 0 live.
- **Round 0:** two chained turns (playback commit, then an internal `prepare_questions` command with an idempotent `int_...` event id).
- **Follow-ups:** depth <= 2, follow-ups <= 40% of base questions, one per need; a second vague answer is assumed visibly. **Budgets:** Quick 5, Standard 12, Thorough 25 (follow-ups included). **Stops:** coverage, budget, fatigue, "that's enough" / finish with defaults. "I do not understand" rewrites once (`cmp.rephrase_question`); "I do not know" simplifies once then records you-decide.
- **Brief:** new optional read-only list `domain_facts`; `meta.interview` block (excluded from the hash); `DiscoveryPlan.interview_budget`; hash stable (stored-fixture test). `compile_ledger` fills EMPTY slots only; every active fact is cited, placed in `domain_facts`, or `not_used` with a reason; leftovers are placed and counted in `meta.interview.facts_unreferenced`. Consumer views carry facts tagged for that consumer, values only, no quote.
- **Spend:** `ledger_spend.compass_spent_micros()` adds the committed cost of every `cmp.*` reservation in the gateway ledger; `CompassBudget` reconciles with it.
- **UI:** groups, answer-all form, why-popover, Ask me more, Q&A editor, MOCK banner, fallback badge, Brief row pulse, visible wait hint, layout switch re-sends unanswered questions. The "Details we captured" Brief-page section from prompt 02 is **not confirmed** in the report.

# External tools, data and free tiers for the Spec engine: web research (2026-11-14)

**Rule from the owner (2026-11-14):** "the free one is the best one; free or trial; for anywhere it can help in our spec engine only." So this note keeps only what is free, open source or has a free tier, and only where it helps **Spec itself**. Front-end tools are listed at the end for completeness and are **not** Spec dependencies.
**How to read it:** these are web search results (many third-party blogs and aggregators), gathered on 2026-11-14. Each line says what the sources say and where they disagree. **Nothing here is verified by running it**; the builder must confirm each item (a one-line test per tool is in the final architecture, doc 18 §7) before depending on it. Searches contained no project details.

## 1. Free Python libraries that Spec can run inside its own code (deterministic, no model, no network)
| Tool | What it gives Spec | Evidence from the search | Caveat |
|---|---|---|---|
| **Faker** (Python) | seeded, reproducible fake rows (names, addresses, phones, dates) | **Corrected 2026-11-14 against Faker's own locales page:** `en_IN` (address, bank, person, phone_number, ssn), `hi_IN` and **`mr_IN`** (address, date_time, person, phone_number) exist, also `gu_IN`, `or_IN`, `ta_IN`; **no `kn_IN`**. A fixed seed reproduces output; missing providers fall back to English. The third-party `indic-faker` claims more Indian languages (kn, mr) | **Kannada has no provider**: a small curated name and place pool (or vet `indic-faker`). Do not use Faker's `ssn`, `bank` providers or its random phone numbers. The first version of this row said Marathi was not found: that was wrong. The faker-js (JavaScript) docs list `en_IN`; Hindi and Marathi there were not confirmed |
| **Babel** (CLDR data) | currency, number and date formats, units, plural rules per locale (Indian digit grouping such as 12,34,567) | CLDR defines two grouping sizes for the Indian style; a JDK bug shows implementations can get en_IN wrong | **Babel's own output was not confirmed**; S0 adds a test that `format_decimal(1234567.891, locale="en_IN")` gives Indian grouping |
| **phonenumbers** | valid-looking example phone numbers per region, formats | `example_number(region)` exists | the India sample was not shown; test it |
| **python-stdnum** | format and checksum checks for India GSTIN, PAN, Aadhaar | modules `in_.gstin`, `in_.pan` exist; checks are structure and checksum, not registration | **Never generate real-looking government ID numbers for people**; use documented test values or fail the checksum on purpose, and mark them synthetic |
| **pycountry**, **zoneinfo**/tzdata, **python-holidays** | ISO countries, currencies, languages; time zones; regional holidays | standard, widely used | not searched; confirm versions |
| **coloraide** | colour science (HCT from Google's Material work, CAM16; its contrast page lists WCAG 2.1 and L*; APCA appears in an issue thread but was **not confirmed** on the contrast page) for accessible palettes and dark mode from a seed colour | HCT tone gaps give contrast guarantees (about 40 gives 3:1, about 50 gives 4.5:1, per a Go library's docs); wide-gamut capable | tone is a proxy: **always compute the real ratio and assert it**; the palette-generation recipe is ours to write. The official Material library is TypeScript, not Python |
| **openapi-spec-validator**, **jsonschema**, Pydantic | contract and schema lint | Spectral and Redocly CLI (Node) are the usual linters; OpenAPI 3.1 differs from 3.0 and breaks tools that assume 3.0 | Spectral and Redocly need Node; keep them optional at proof time |
| **tiktoken** and provider token counters | token budgets | not searched | use a provider counter where one exists, else the conservative factor |

## 3. Free LLM tiers for proof and provider-switch tests (never for real customer data)
Gemini API free tier (shared with AI Studio; **data may be used to improve Google products**), Groq (standing free tier, per-model limits), Cerebras (about 1M tokens a day), Mistral (free experimentation tier), OpenRouter `:free` models (20 requests a minute, 50 a day, 1,000 a day after USD 10 of credits), Z.ai GLM Flash (listed free, limits not given), NVIDIA NIM (dev and test only), Cloudflare Workers AI (small daily allowance). Alibaba Model Studio's free quota was **not confirmed**. **Use synthetic inputs only on these tiers** (the nine exports are synthetic or the owner's own test data).

## 4. How the non-American providers handle structured output (decides our call contract)
- **DeepSeek:** JSON mode (`json_object`) is documented and does not enforce a shape; strict tool-calling is a beta; **`json_schema` support is contested** (one 2026 compatibility test says unavailable).
- **Qwen (Alibaba Model Studio, OpenAI-compatible):** `json_object` and `json_schema` are documented, model coverage varies; `json_object` needs the word "json" in the prompt.
- **Kimi (Moonshot):** `json_schema` with a `strict` flag and its own schema dialect; reliability differs by model.
- **MiniMax, GLM:** no official docs found; one host lists MiniMax-M2 as JSON mode only.
- **OpenRouter:** support is per endpoint (386 of 469 model IDs listed `structured_outputs` on 2026-10-08, per its blog); a `require_parameters` option exists (from a mirror of the docs).
- **Consequence:** the portable contract is "return one JSON object", **validated locally, one repair, then a fallback**, with the strictest available mode chosen by the gateway; the prompt template contains the word JSON; schemas stay flat and small (doc 15 §11).
- **Prompt caching differs too:** OpenAI automatic (prefix of about 1,024 tokens or more), Anthropic explicit (reads about a tenth of input price; 5-minute or 1-hour life), Gemini implicit plus explicit objects, DeepSeek automatic disk cache, Qwen implicit plus explicit. A stable leading prefix works under all of them; nothing may depend on caching.

## 5. Translation (for the extra-locale pass)
Google Cloud Translation: NMT USD 20 per million characters after **500,000 free characters a month**; a translation-LLM tier USD 10 per million input and output characters (the page snippets disagree). IndicTrans2 (free, open) ranked second on English to Hindi in one comparison, Google better on back-translation checks; **no Marathi or Kannada head-to-head was found**. A small model costs about USD 0.01 per locale at the recorded prices, so **an LLM is cheaper than commercial translation at our volume**; machine translation stays an optional port behind a quality test, and every non-English locale is flagged `needs_native_review`.

## 6. Front-end tools (NOT Spec dependencies; Spec only states needs, and the capability sheet records what exists)
- **Expo:** SDK 58 is the newest in the results (2026-10-15, React Native 0.88 line); the Legacy Architecture was dropped from SDK 55 (React Native 0.83). Expo hosts an official MCP server (`mcp.expo.dev/mcp`, OAuth with an Expo account: current docs, build history, updates, TestFlight) and Expo Skills plugins for Claude Code and Codex.
- **Component-library tools:** `@heroui/native-mcp` (HeroUI Native docs), a third-party shadcn-ui MCP that covers react-native-reusables, a Reacticx MCP. **No MCP for gluestack, Tamagui or React Native Paper was found.** The 2026 roundups name Tamagui (v2, 2.7.x), gluestack-ui (copy-in, a v5 reported June 2026 on NativeWind v5), React Native Paper (Material 3), HeroUI Native, Expo UI (early). Versions come from blogs; check the changelogs.
- **Docs and design:** Context7 (MIT server, closed backend), a Figma MCP (not verified).
- **Images, icons, animation:** Unsplash API (demo 50 requests an hour, production 5,000 after review, attribution and hotlinking and download-tracking rules, keys must stay private), Pexels, Lorem Picsum, DiceBear (code MIT, **each avatar style licensed separately**), LottieFiles (an official hosted MCP and a community server), Iconify (not searched).
- **Motion:** Reanimated 4 adds CSS-style animations and transitions; **shared element transitions are still experimental behind a flag in the official notes** (several blogs claim stable).
- **Testing:** Maestro flows are YAML (`launchApp`, `tapOn`, `assertVisible`), selected by `testID`; with Expo Go use `openLink` (not `launchApp` with a custom id); Expo supports Maestro Cloud in EAS Workflows. MSW works in React Native tests with polyfills and `msw/native`; it is rough in Expo.
- **Tokens:** Style Dictionary v4 added the W3C DTCG format and v5 is reported to follow the 2025.10 revision (vendor source); DTCG 2025.10 is the first stable edition.
- **Evals:** promptfoo (open source) compares providers and asserts JSON schemas; its CI exit-code behaviour is described two ways, so verify the installed version.

## Corrections after the independent review of doc 18 (2026-11-14)
An independent reviewer checked this note's tool claims against the vendors' own pages; I re-checked the first two myself. Where the note or doc 18 v1 said more than the sources do, or was wrong:
- **Faker has a Marathi locale** (`mr_IN`: address, date_time, person, phone_number) and `hi_IN`, `en_IN`, `gu_IN`, `or_IN`, `ta_IN`; **it has no Kannada** (`kn_IN` is not on its locales page). Earlier text said "Marathi and Kannada not found": wrong for Marathi. `en_IN` also ships `ssn` and `bank` providers: do not use them for mock data.
- **Big List of Naughty Strings has 35 categories** (re-read from the raw file on 2026-11-14), including script, SQL, server-code, command, XXE and jinja2 injection (one payload targets memory exhaustion), "Known CVEs and Vulnerabilities", terminal escape codes and "iOS Vulnerabilities" (strings that crashed iMessage on some iOS versions). Only a small **allow-list of display-safe categories** may enter mock data (doc 18 §6).
- **python-stdnum checks structure and checksum** (the Aadhaar module uses Verhoeff), so it **accepts** a valid-looking number; the right use is to **fail a fixture that contains any value passing `validate()`**, not to "reject accidental real-looking values". Its licence is LGPL-2.1 or later (pycountry is LGPL as well, unverified): record both in S0.
- **phonenumbers** `example_number` gives one fixed documented number per region; numbers from random generators (Faker's included) can belong to real subscribers: use documented examples or masked forms only.
- **coloraide:** the contrast page lists WCAG 2.1 and L*, not APCA; the design asserts the WCAG 4.5:1 ratio, so nothing depends on APCA.
- **promptfoo** requires Node 22 or newer (proof only; the run path stays Python-only). Spectral and Redocly also need Node.
- **openapi-spec-validator:** PyPI lists OpenAPI 2.0, 3.0 and 3.1 (reviewer's check; confirm in S0). The first draft named it without a search.
- **Babel:** its numbers page shows no `en_IN` example, so Indian digit grouping remains **unconfirmed**; S0 tests it.
- **Free LLM tiers and the nine exports:** the nine Compass exports are real exports (three approved Briefs and six test inputs); I have not confirmed they hold no personal data, so free tiers see only the four synthetic inputs until the owner confirms (OI-43).
- **Translation services** (Google Cloud Translation, IndicTrans2 hosted) send app text to a third party and need an account: outside the "no network call in Spec's run except the LLM gateway" policy; only with the owner's yes.

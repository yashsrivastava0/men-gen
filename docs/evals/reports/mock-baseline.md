## Honesty notes

- Mock mode: cost per session is zero and latency is the fake clock; neither says anything about the real model. Read cost and latency from a live batch (L3).
- The mock handlers are deterministic and schema-valid by construction, so the first-pass validator rate and the proposal acceptance share here measure the pipeline and the content files, not Luna. Expect a small model to be weakest at spec proposals (C9, C10), the critic (C12) and repairs (C13); batch L3 and L4 report that.
- The sufficiency probe is answered offline by a rule-based reader of the slice text, so it can only fail when the slice lacks a field. A live run (L4) adds the model's own reading errors.
- Injection payloads are blocked structurally (screen, untrusted blocks, code validation); the detection rate is reported separately and is a tripwire, not a guarantee.

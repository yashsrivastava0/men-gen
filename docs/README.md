# Docs index

Everything about the Context Engine lives here. Every behavior change updates `docs/` (hard rule 11). Every page below exists; `uv run python scripts/docs_check.py` (`just docs-check`) fails when an indexed link breaks or markdown appears outside the allowed places. Generated files are produced by `just gen-docs` / `just export-schemas`, never edited by hand.

Start with [../CLAUDE.md](../CLAUDE.md) (commands, hard rules) and [../README.md](../README.md) (quickstart).
